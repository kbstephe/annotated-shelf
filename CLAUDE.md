# The Annotated Shelf

Personal audio-essay series (Matter mode: markdown → GitHub Pages → full-text
RSS → Matter's TTS narrates). Public repo — nothing personal or sensitive in
any file.

**NEW SESSION?** Read `STATE.md`, then the last entry of `PROJECT_LOG.md`.

Where things live:
- How to write/publish an episode: `.claude/skills/audio-essay/SKILL.md`
- Craft charter (read before every script): `.claude/skills/audio-essay/SCRIPT_STYLE.md`
- Research behind the charter: `.claude/skills/audio-essay/references/craft-research-aug2026.md`
- Reading list / TODO role: `queue.md` (the Order of record block at the top is binding)
- Who the listener is: `listener.md`
- Running frames for callbacks: `FRAMES.md` (`scripts/frames.py` shows where each appears)
- Mandatory pre-commit lint: `scripts/lint_script.py`
- Fetch routes that work from the cloud: `.claude/skills/audio-essay/references/sourcing-routes.md`
- Feed title, description, base_url: `config.json`
- Reviews and audits: `reviews/`; old log and STATE snapshots: `archive/`
- Session history: `PROJECT_LOG.md`
- End of session or Routine run: `.claude/skills/done/SKILL.md` (log entry + STATE snapshot)
