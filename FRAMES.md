# FRAMES — the shelf's running frames

A concordance of the ideas the shelf keeps, so a callback carries the
mechanism and not just the name. The charter treats callbacks as spaced
repetition; this file is how a writer finds them without re-reading old
scripts. Use a frame only where it genuinely applies; there is no quota.

`python3 scripts/frames.py` prints where each frame has appeared (first and
last episode, count), computed from the scripts. `python3 scripts/frames.py
episodes/NNN-slug.md` lists the frames a draft touches and the ten longest
unused. When an episode plants a new frame the shelf should keep, add a row.
Keys are case-sensitive regexes; keep them distinctive (a bare surname such as
Scott or Campbell matches the wrong people).
